OMG Salt for VCF Tools

We are housing and sharing individual tools built to support the VMware Salt for VCF functionality here.

First up is the first static webform for building sets of Salt State and Jinja Files for each VCF Component. To programmatically manage the available VCF Configuration settings at scale, from the Salt for VCF level, you need to know which settings are available, how those settings need to be presented to the Salt for VCF API in order for the embedded Salt infrastructure to process your request.

The available Salt for VCF API interfaces are referenced in the official Broadcom developer portal.

The available settings are also documented in the VCF Configuration IDs section.

This webform can be used online for you to generate the needed Salt State and Jinja files or you can download the webform and use it offline. The webform is entirely self contained and does not need any connection to work.
